Como usar o DocNum

Escreva o documento normalmente. Declare um dado ou cálculo no início da linha com @ nome = valor — o tipo (número, data, mês/ano ou hora) é detectado sozinho pelo formato do valor, e o campo aparece no próprio documento. Você pode referenciar em qualquer lugar do texto com @nome. : e # continuam funcionando (compatibilidade), mas não são mais necessários.

1. Número

@ valorAcordo = 8500
@ percentualPatronal = 20%
@ contribuicaoPatronal = valorAcordo * percentualPatronal

Aceita + - * / ( ) ^ e porcentagem. ^ é potência: (1 + 5%)^3 calcula juros compostos.

2. Hora

@ entrada = 08:00
@ saida = 17:30
@ horasTrabalhadas = saida - entrada

Formato HH:MM. Some ou subtraia hora com hora. Multiplicar ou dividir por número converte para decimal.

3. Data

@ dataAdmissao = 15/03/2026
@ diasExperiencia = 90
@ fimExperiencia = dataAdmissao + diasExperiencia

Formato DD/MM/AAAA. Data mais número soma dias; data menos data dá a diferença em dias.

4. Mês/Ano

@ inicioDesconto = 05/2026
@ fimDesconto = inicioDesconto + 3

Formato MM/AAAA, exibido por extenso (ex.: Maio/2026).

5. Variável inline (declarar no meio do texto)

O {{@anuenio = 2%}} de @salarioBase, ou seja, [salarioBase * anuenio].

Declara e mostra "Rótulo: valor" no próprio lugar (tanto com {{ }} quanto com [ ]), sem precisar de uma linha separada.

6. Cálculo direto no texto, sem variável

O saldo é [100-50]. A diferença de dias é [dataDemissao - dataAdmissao].
