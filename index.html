Como usar o DocNum

Escreva o documento normalmente. Declare um dado ou cálculo no início da linha com @ (número), : (hora) ou # (data) — ele aparece no próprio documento, e você pode referenciá-lo em qualquer lugar do texto com @nome.

1. Número

@ valorAcordo = 8500
@ percentualPatronal = 20%
@ contribuicaoPatronal = valorAcordo * percentualPatronal

Aceita + - * / ( ) ^ e porcentagem. ^ é potência: (1 + 5%)^3 calcula juros compostos.

2. Hora

: entrada = 08:00
: saida = 17:30
: horasTrabalhadas = saida - entrada

: horasSegunda = 08:00
: horasTerca = 09:15
: totalSemana = horasSegunda + horasTerca

Formato HH:MM. Some ou subtraia hora com hora — a subtração serve tanto para calcular duração entre dois horários (entrada/saída) quanto a soma para acumular horas (sem limite de 24h, útil para total de horas extras no mês).

Multiplicar ou dividir hora por número converte para decimal e o resultado vira dinheiro/número — não continua sendo hora:

@ valorHora = 25
: horasExtras = 02:30
@ valorExtra = valorHora * horasExtras

3. Data

# dataAdmissao = 15/03/2026
@ diasExperiencia = 90
# fimExperiencia = dataAdmissao + diasExperiencia

# dataDemissao = 20/06/2026
@ diasTrabalhados = dataDemissao - dataAdmissao

Formato DD/MM/AAAA. Data mais número soma dias; data menos número volta dias; data menos data dá a diferença em dias.

4. Usar o valor no texto

O acordo foi de @valorAcordo.
Trabalhou @horasTrabalhadas no dia @dataAdmissao.

@nome funciona igual para número, hora e data — só substitui se nome já foi declarado; caso contrário mantém o texto original.

5. Mostrar "@algo" sem calcular

Escreva "@naoCalcular" para mostrar o texto tal como está.

Entre aspas simples '...' ou duplas "...".

6. Tabelas

| Descrição | Valor |
|---|---:|
| Acordo | @valorAcordo |
| Horas | @horasTrabalhadas |

Documentos antigos

A sintaxe anterior continua funcionando:

salarioBase = 3500
valorHora = salarioBase / 220
O valor da hora é {{ valorHora }}.

Essas declarações (sem @/:/#) ficam invisíveis — só aparecem via {{ }} ou [ ].

7. Cálculo direto no texto, sem variável

O saldo é [100-50].
A diferença de dias é [dataDemissao - dataAdmissao].

[ ] funciona igual a {{ }}: calcula qualquer expressão (números, variáveis já declaradas, hora ou data) direto no meio do texto, sem precisar declarar uma variável nova.

Limitações conhecidas

  • Hora não trata virada de meia-noite (turno que começa num dia e termina no outro).
  • Um título de seção que por acaso siga o formato # nomeDaVariavel = valor é interpretado como declaração de data, não como cabeçalho — evite esse padrão exato em títulos.
