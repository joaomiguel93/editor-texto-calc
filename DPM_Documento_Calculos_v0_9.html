Como usar o DP Calc

Escreva o documento normalmente. Use @ para declarar um dado ou cálculo — ele aparece no próprio documento, e você pode referenciá-lo em qualquer lugar do texto.

1. Declarar um dado ou cálculo

@ valorAcordo = 8500
@ percentualPatronal = 20%
@ contribuicaoPatronal = valorAcordo * percentualPatronal

Cada linha @ nome = valor aparece no documento como uma linha de dado/cálculo, na ordem em que foi escrita.

2. Usar o valor no texto

O acordo foi de @valorAcordo.
A contribuição patronal foi @contribuicaoPatronal.

Só é substituído quando o nome depois do @ corresponde a uma variável já declarada — caso contrário, o texto fica como está (útil para e-mails ou menções).

3. Mostrar "@algo" sem calcular

Coloque entre aspas simples ou duplas para exibir o texto literal, sem tentar substituir.

Escreva "@naoCalcular" para mostrar o texto tal como está.

4. Porcentagens

Digite de forma natural — 20% vale 0,20 internamente.

5. Tabelas

| Descrição | Valor |
|---|---:|
| Acordo | @valorAcordo |
| Patronal | @contribuicaoPatronal |

Documentos antigos

A sintaxe anterior continua funcionando, para não quebrar arquivos já salvos:

salarioBase = 3500
valorHora = salarioBase / 220
O valor da hora é {{ valorHora }}.

A diferença: essas declarações (sem @) ficam invisíveis no documento — só aparecem via {{ }}.
